## The image

A 1024×1024 PNG, 591,215 bytes (under the 1 MiB limit). The program writes it to `/output/entry.png`.

## Files

- `entry.png` — the 1024×1024 catalogue photograph the program writes out.
- `main.ts` — the entrypoint: copies the committed `entry.png` to the output directory, deterministically, with no clock and no network — both graded runs write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
